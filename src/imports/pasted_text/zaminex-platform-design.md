PROJECT OVERVIEW

Zaminex is NOT a website.

Zaminex is NOT a generic CRM.

Zaminex is a complete Real Estate Operations Platform used internally by a real estate company.

The platform manages the entire business workflow.

Main Workflow:

Consultant
→ Registers Property
→ Creates Listing
→ Receives Tasks
→ Updates Task Status
→ Creates Follow-Ups
→ Management Monitors Performance
→ Executive Team Reviews Analytics

The entire platform must revolve around this workflow.

Properties are the central object of the system.

Listings, Tasks, Follow-Ups, Analytics and Reports are connected to Properties.
